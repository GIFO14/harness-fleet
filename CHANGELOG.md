# Changelog

This project follows Semantic Versioning.

## [Unreleased]

- Adapter contract fixtures and broader cross-platform process-tree tests.
- Additional live harness fixtures and release assets.

## [0.1.1] - 2026-09-17

- Added conversational pre-launch plan revisions in the web panel and CLI.
- Added atomic DAG replacement with schema and capability validation while preserving the human launch gate.
- Fixed imported-fleet launch recursion and Pi RPC process settlement.
- Refined the live control panel for clearer statuses, activity, actions, reports, and unknown-cost handling.
- Removed npm registry publishing; releases are distributed directly from GitHub.

## [0.1.0] - 2026-08-31

- Extracted the fleet core into a standalone local daemon.
- Added mixed Pi, Claude Code, and Codex fleets.
- Added mandatory recoverable orchestrators and human launch confirmation.
- Added SQLite WAL state, immutable attempts, messaging, capability tokens,
  reviewer loops, worktrees, budgets, restart recovery, CLI, and web canvas.
- Added public documentation, examples, tests, and release automation.
